Perfect Roku App Tutorial

A practical checklist for building Scratch projects that convert cleanly.

1

Name a manifest sprite

Create a sprite named rokusmanifest, add one Scratch comment/note inside it, and write Roku manifest lines like title=My Game.

2

Design for the remote

Use arrows, select, back, replay, and a few letter keys. The Play/Pause button is reserved for Scratch start/stop.

3

Keep assets Roku-friendly

Use simple costumes and short sounds. SVG costumes are converted to PNG during export, but camera/video sensing, pen drawings, and clone-heavy effects still need manual work.

4

Ship in layers

First convert the stage and sprites, then wire the generated BrightScript notes into real SceneGraph behavior one Scratch feature at a time.
